# История изменений

## 0.1.0 — 2026-11-21 (проект редакции, тег не опубликован)

- Определены границы upstream, стандарта, платформы и продукта.
- Добавлены русскоязычные артефакты Markdown + YAML frontmatter, каталог и шаблоны.
- Описаны профили, подключение, проверка, обновление upstream и миграция документов.
- Сохранены upstream-пути `spec/`, `tasks/plan.md`, `tasks/todo.md`; патчи skills не используются.

### Уточнение структуры — 2026-11-21

- По запросу пользователя HLD объединён в один файл, каталог ADR сделан плоским.
- Убраны отдельные артефакты влияния, проверки, эксплуатации и безопасности; необходимое содержание перенесено в план, задачи и HLD/LLD.
- Пути карты возможностей и модульных SPEC сверены с закреплённым upstream.
- Добавлены учебные русскоязычные примеры со схемами и ссылками на публичные первоисточники.
- Разделены имена индекса шаблонов и шаблона README для файловых систем без учёта регистра.
- Убрана JSON Schema метаданных: требования к frontmatter, полям и допустимым значениям описаны в [метаданных](docs/metadata.md) и проверяются структурной проверкой.
