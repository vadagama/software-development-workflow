# Правила сопровождения стандарта

Этот репозиторий содержит платформенно-независимый стандарт разработки. Начинай с [README](README.md), [карты upstream](docs/upstream.md) и [правил эволюции](docs/evolution.md).

- Максимально переиспользуй оригинальные `addyosmani/agent-skills`. Не копируй их процедуры и не создавай skill с тем же назначением ради нового пути документации.
- Авторские документы и шаблоны пиши на русском в Markdown с YAML frontmatter. Технические ключи, пути и идентификаторы не переводи.
- Изменяя требование, согласованно обновляй каталог, шаблоны, примеры и CHANGELOG. Не добавляй требования к конкретному стеку: они принадлежат платформе.
- Различай действующие возможности и планы автоматизации. Конфигурация не является исполняемым установщиком; структурная проверка метаданных не проверяет смысл архитектуры.
- Проверяй Markdown-ссылки, метаданные, уникальность ID и сценарии из [правил проверки](docs/validation.md). Шаблоны и примеры не являются заполненными документами продукта.
- Не меняй upstream SHA без чтения diff и проверки мест интеграции. Совместимость с хостами не объявляй без выполнения их сценариев.
- Не удаляй историю решений и не мигрируй продуктовые репозитории как побочный эффект изменения стандарта.
