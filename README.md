# Стандарт процесса разработки

Этот репозиторий — надстройка над [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills): основа управления процессом — upstream skills; здесь — каталог продуктовых артефактов документации, профили процесса и шаблоны. Сами upstream skills не копируются и не переписываются.

Четыре источника составляют правила конкретного продукта:

| Источник | Ответственность |
| --- | --- |
| `addyosmani/agent-skills` | Инженерные практики, выполнение работы и проверка результата |
| `software-development-workflow` | Каталог продуктовых документов (HLD, API, события, данные, долг), формат метаданных, настройка и развитие процесса |
| Платформа, например `go-product-platform` | Допустимый стек, СУБД, инфраструктура, структура исходников и команды проверки |
| Репозиторий продукта | Выбранный профиль, требования продукта, реальные документы и код |

Все создаваемые документы продукта пишутся **на русском языке в Markdown с YAML frontmatter**. Ключи метаданных, enum, идентификаторы, пути, код и имена API сохраняют техническое написание. Документы хранятся в Git продукта, включая HLD, контракты, данные и долг; специфичные upstream-артефакты (спецификации, планы, CONSTRAINTS, ADR) — там же по их конвенциям.

## Подключение

1. Прочитайте [контракт интеграции и профили](docs/integration.md).
2. Зафиксируйте commit этого стандарта, upstream и платформы в продукте по [примеру конфигурации](examples/workflow.yaml). Пример требует заполнения, это не установщик.
3. Добавьте в правила агента [инструкции подключения](examples/product-agents.md). Установите upstream по его документации, проверьте соответствие выбранному SHA.
4. Создайте минимальные документы по [каталогу артефактов](docs/artifacts.md), используя [шаблоны](templates/README.md). Инициализацию и ведение артефактов выполняет агент по скиллу [`software-development-workflow-addons`](skills/software-development-workflow-addons/SKILL.md). Остальные документы создавайте по факту необходимости.
5. Выполняйте [процесс разработки](docs/upstream.md), проверяя документацию вместе с кодом.

Текущая редакция: `0.1.0`, проект стандарта для применения и проверки на продуктах. В репозитории доступны правила, шаблоны и скилл `software-development-workflow-addons` — процедура агента для инициализации и ведения артефактов. Автоматического установщика, генератора, валидатора CLI и интеграции с трекерами пока нет: скилл выполняется агентом, а не запускается сам. YAML-конфигурация интерпретируется агентом или человеком по правилам этого стандарта; она сама не запускает skills.
