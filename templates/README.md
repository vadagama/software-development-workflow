# Шаблоны документов

Шаблоны задают минимальное содержание. Перед использованием замените ID, название, владельца, даты и все подсказки. Заполненный документ должен содержать факты, ссылки и явно обозначенное неизвестное. Дата из шаблона не является датой создания продуктового документа.

Обязательность определяется [каталогом](../docs/artifacts.md) и [профилем](../docs/integration.md). Несуществующие разделы не заполняются выдуманными данными: объясните неприменимость. Frontmatter проверяется по [контракту метаданных](../docs/metadata.md). Создание и обновление документов из шаблонов в продукте выполняет агент по скиллу [`software-development-workflow-addons`](../skills/software-development-workflow-addons/SKILL.md).
